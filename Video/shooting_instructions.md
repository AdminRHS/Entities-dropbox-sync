## General Shooting Workflow

### Phase 1: Pre-Production (Day Before)

**1. Confirm Shoot Details**
- [ ] Date and time locked
- [ ] Location address saved
- [ ] Weather forecast checked
- [ ] Backup plan prepared

**2. Equipment Preparation**
- [ ] Check all batteries (charge if needed)
- [ ] Format memory cards
- [ ] Clean lenses and sensors
- [ ] Test all equipment
- [ ] Pack in organized bags

**3. Clothes Selection**
- [ ] Review clothes_catalog.md
- [ ] Select outfit matching video style
- [ ] Check for wrinkles/damage
- [ ] Prepare backup outfit
- [ ] Iron/steam if needed

**4. Content Planning**
- [ ] Shot list created
- [ ] Script/talking points ready
- [ ] Reference images collected
- [ ] Timing estimated

**5. Logistics**
- [ ] Travel time calculated
- [ ] Parking researched
- [ ] Permits obtained (if needed)
- [ ] Contact information saved

---

### Phase 2: Production (Shoot Day)

**Setup (First 30 minutes)**

**1. Arrive Early**
- Arrive 30-60 minutes before shoot
- Survey location
- Check lighting conditions
- Note any issues

**2. Equipment Setup**
```
Order of setup:
1. Tripod/stabilizer
2. Camera body
3. Lens attachment
4. Battery + memory card check
5. Lighting (if indoor)
6. Audio equipment
7. Test shot
```

**3. Technical Checks**
- [ ] Exposure correct (not too bright/dark)
- [ ] Focus sharp
- [ ] White balance set
- [ ] Audio levels good
- [ ] Frame composition
- [ ] No distractions in background

**4. Test Recording**
- Record 10-second test clip
- Play back to verify:
  - Image quality
  - Audio quality
  - No camera shake
  - Correct settings

**Execution (Main Shoot)**

**1. Follow Shot List**
- Work through shots systematically
- Check off completed shots
- Note any variations

**2. Multiple Takes**
- Shoot 2-3 takes minimum
- Vary delivery/angles
- Give yourself editing options

**3. B-Roll Collection**
- Shoot extra footage:
  - Establishing shots
  - Detail shots
  - Cutaways
  - Transitions

**4. Continuous Monitoring**
- Check footage every 3-5 shots
- Verify exposure hasn't changed
- Audio still good
- Focus still sharp

**5. Safety Shots**
- Before leaving:
  - Review all critical footage
  - Verify all shots captured
  - Check memory cards not corrupted
  - Shoot backup if unsure

**Wrap (Final 15 minutes)**

**1. Final Checks**
- [ ] All shots on shot list completed
- [ ] All memory cards accounted for
- [ ] No equipment left behind
- [ ] Location restored (if needed)

**2. Equipment Teardown**
```
Reverse order of setup:
1. Turn off audio equipment
2. Remove camera accessories
3. Remove lens (cap on)
4. Remove battery
5. Remove memory card → case
6. Pack lighting
7. Pack tripod last
```

**3. Quick Organization**
- Label memory cards
- Note shoot details on card case
- Pack equipment securely

---

### Phase 3: Post-Production (Same Day)

**Immediate Tasks (Within 2 Hours)**

**1. Backup Footage**
- [ ] Insert memory card
- [ ] Create dated folder: YYYY-MM-DD_project_name
- [ ] Copy all footage to Google Drive
- [ ] Copy all footage to local backup
- [ ] Verify both copies complete
- [ ] Do NOT format card until verified

**2. Quick Review**
- Scrub through footage
- Note any issues
- Flag best takes
- Identify problems

**3. Organization**
- [ ] Rename files with descriptive names
- [ ] Create project folder structure
- [ ] Move to appropriate Google Drive folder
- [ ] Update content_calendar.md
- [ ] Log shoot details

**4. Task Creation**
- [ ] Create editing task in todo
- [ ] Set deadline
- [ ] Note any special requirements
- [ ] Link to footage location

**Next Steps**
- [ ] Format memory cards (after verification)
- [ ] Charge all batteries
- [ ] Clean equipment
- [ ] Return to storage organized

## Shoot Type Specific Instructions

**Pre-Production Specifics:**
- Script written word-for-word
- Key points highlighted
- Visual aids prepared
- Demo materials ready

**Setup:**
- Clean, uncluttered background
- Good lighting (soft, even)
- Camera at eye level

**Execution:**
- Record intro separately

- Repeat unclear sections
- Show, don't just tell

**B-Roll Needed:**

## Technical Settings Guide

### Camera Settings

**Indoor Shooting:**
```
Shutter Speed: 1/50 (for 24fps) or 1/60 (for 30fps)
Aperture: f/2.8 - f/5.6 (depending on depth of field)
ISO: 400-1600 (minimize noise)
White Balance: Indoor (3200K) or custom
Frame Rate: 24fps (cinematic) or 30fps (standard)
```

**Outdoor Shooting:**
```
Shutter Speed: 1/50 or 1/60 (same as indoor)
Aperture: f/4 - f/8 (sharper, more depth)
ISO: 100-400 (lower in bright light)
White Balance: Daylight (5600K) or auto
Frame Rate: 24fps or 30fps (consistent with indoor)
```

### Audio Settings

**Levels:**
- Peak at -12dB to -6dB
- Never hit 0dB (clipping)
- Consistent across takes

**Monitoring:**
- Use headphones always
- Check for background noise
- Listen for wind/handling noise
- Verify levels during recording

## Common Issues & Solutions

### Issue: Footage Too Dark
**Solution:**
- Increase ISO (watch for noise)
- Open aperture (lower f-number)
- Add lighting
- Increase exposure compensation

### Issue: Audio Has Noise
**Solution:**
- Move mic closer to subject
- Use windscreen outdoors
- Reduce gain if too high
- Check for electronic interference

### Issue: Focus Not Sharp
**Solution:**
- Use manual focus
- Increase aperture (higher f-number)
- Check lens is clean
- Verify camera is stable

### Issue: Camera Shake
**Solution:**
- Use tripod/stabilizer
- Increase shutter speed (if possible)
- Brace camera against solid object
- Use wider lens
