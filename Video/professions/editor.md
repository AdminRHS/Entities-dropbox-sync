# Video Editor

**Department:** Video Production
**Level:** Mid
**Entity:** VID
**Code:** VID.EDITOR

---

## Overview

Video editors transform raw footage into polished final videos through cutting, color grading, audio mixing, and effects application.

---

## Responsibilities

### Primary
- Import and organize footage
- Edit videos according to creative brief
- Color correction and grading
- Audio editing and mixing
- Add graphics, titles, transitions
- Export final deliverables in multiple formats
- Manage project files and versions

### Secondary
- Provide creative input on storytelling
- Optimize videos for different platforms
- Archive completed projects
- Maintain editing software and plugins
- Collaborate with directors on vision

---

## Skills Required

### Technical Skills
- Non-linear editing (Adobe Premiere, Final Cut Pro, DaVinci Resolve)
- Color grading and correction
- Audio editing and mixing

- Visual rhythm and timing

## Daily Workflow

### Project Start
1. Import footage from Google Drive
2. Create project structure
3. Organize clips by scene/type
4. Create proxies if needed
5. Review all footage
6. Log best takes

### Editing Phase
1. Assembly edit (rough cut)
2. Refine timing and pacing
3. Add transitions
4. Color correction pass
5. Audio editing and mixing
6. Graphics and titles
7. Final polish

### Delivery Phase
1. Client/director review
2. Incorporate feedback
3. Final color grade
4. Audio mastering
5. Export multiple formats:
   - 4K master
   - 1080p web
   - Mobile-optimized
   - Thumbnail image
6. Upload to Google Drive
7. Archive project files

## Export Specifications

### Standard Deliverables

**4K Master**
```
Resolution: 3840x2160
Frame Rate: 24fps or 30fps
Codec: H.264 or ProRes
Bitrate: High (100+ Mbps)
Audio: AAC 320kbps stereo
```

**1080p Web**
```
Resolution: 1920x1080
Frame Rate: Match source
Codec: H.264
Bitrate: 8-12 Mbps
Audio: AAC 192kbps stereo
```

**Mobile Optimized**
```
Resolution: 1080x1920 (vertical) or 1920x1080
Frame Rate: 30fps
Codec: H.264
Bitrate: 5-8 Mbps
Audio: AAC 128kbps stereo
```

**Thumbnail**
```
Format: JPG
Resolution: 1920x1080
Quality: High (90%)
```
